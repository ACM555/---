# Outbound-Guard 设计系统

本规范来自 Stitch Gemini 3.1 Pro 生成的桌面与移动端方案，并已按现有 React 18、Ant Design 5 与 FastAPI 数据契约校准。

## 设计方向

- 产品定位：面向中国出海企业、商标代理人与法律审核人员的越南商标风险工作台。
- 核心语言：专业、可信、可追溯、高信息效率。
- 桌面结构：主导航、业务内容、流程上下文三层工作台。
- 移动结构：顶部紧凑导航、单列内容、可折叠复杂信息，无页面级横向滚动。

## 语义令牌

- 品牌深色：`#001529`
- 主操作与活动状态：`#006A6A`
- 高亮青绿：`#13C2C2`
- 页面背景：`#F4FBFA`
- 低层表面：`#EEF5F4`
- 主要文本：`#161D1D`
- 次要文本：`#3C4949`
- 边界：`#BBC9C9`
- 高风险：`#BA1A1A`
- 中风险：`#994712`
- 低风险：`#2F7D32`

## 排版与间距

- 中文字体优先使用 `PingFang SC`、`Microsoft YaHei`，英文使用 `Inter` 或系统无衬线字体。
- 移动端正文不小于 16px，正文行高 1.5-1.75。
- 使用 8px 间距系统，4px 仅用于紧凑组件内部。
- 卡片使用 8px 圆角，输入与标签使用 4px 圆角，按钮不得混用无规则的药丸形态。

## 组件规则

- 每个页面只保留一个主要操作，次要操作降低视觉权重。
- 风险状态必须同时使用文字、图标和语义色，不允许只靠红绿区分。
- 卡片默认无阴影，通过背景层次与 1px 边界表达层级。
- 所有交互目标至少 44px，键盘焦点必须清晰可见。
- 加载使用与最终结构匹配的骨架，错误和超时必须提供恢复动作。

## 响应式与无障碍

- 关键断点：390、768、1024、1440px。
- 1280px 以下隐藏右侧上下文栏，900px 以下使用移动导航。
- 支持 `prefers-reduced-motion`，仅对反馈和状态变化使用短时过渡。
- 保持 WCAG AA 文本对比度、顺序化标题层级、表单可见标签和有效的 `aria-label`。
